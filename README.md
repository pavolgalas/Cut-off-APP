# 🎯 Project Cutoff Analysis Tool

## 📊 Live Demo
[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://your-app.streamlit.app)

## 🚀 Usage
1. Upload Excel with project scores
2. View histograms + stats
3. Adjust cutoffs (Q75 recommended)
4. Analyze + Download results

## 📁 Required Columns
- `Final report score (Average)`
- `Absorption rate (Average)`
- `Progress report score`
- `QS report score`
